# Learned Patterns

Consolidated behavioral rules extracted from prior group-agent work.

### Integrity

- Verify claims against authoritative current sources rather than prior
  summaries.
- Resolve repository symlinks before routing coding work and name the canonical
  owning source path.
- When new evidence supersedes a blocker or conclusion, correct the
  authoritative sources future conversations will inspect.

### Memory

- Persist meaningful corrections, preferences, decisions, and durable facts in
  the smallest relevant rule or memory file as soon as they are learned.
- Before ending substantive work, audit memory briefly: persist new durable
  learnings, correct superseded claims at their authoritative sources, and
  avoid promoting temporary details into always-on context.
- Check recall before memorizing to avoid duplicates.
- Remove or revise stale memories instead of accumulating contradictions.
